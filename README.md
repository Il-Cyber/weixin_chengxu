# 青春诗会 · 诗歌接龙（网页版）

团日活动主题的诗歌接龙网页（移动端优先，红色主题）。支持**浏览器 / 微信内置浏览器等多端数据同步**。

## 功能

- 每次进入自动随机分配一种接龙颜色（高饱和、不含白灰）
- 多行输入按回车分行显示
- 常见敏感词自动审查，命中即拦截
- 本人可删除自己发表的诗句，管理员可删除任意诗句（页脚「管理员入口」，口令见 `js/app.js` 的 `ADMIN_CODE`）
- **云端同步**：配置 LeanCloud 后，接龙数据实时共享，不同设备/浏览器打开看到同一首诗

## 使用

直接用浏览器打开 `index.html` 即可预览（建议手机视口或真机）。

## 开启云端同步（可选，推荐）

默认数据存浏览器本地（仅本机可见）。要让**浏览器和微信打开后数据互通**，需配一个免费云数据库（本项目用 LeanCloud）：

1. 注册 LeanCloud：https://console.leancloud.cn （免费开发版即可）
2. 创建应用 → 「设置 → 应用凭证」，复制 **AppID / AppKey / Server 域名**
3. 打开 `config.js`，填入这三项（见文件顶部注释）
4. 刷新页面，底部提示变为「云端已同步 · 所有设备实时共享」即生效

> 说明：网页版为**客户端直连**云数据库，删除权限是"客户端校验本人/管理员"；如需服务端强制校验的更安全版本，请使用 `miniprogram/` 目录下的微信小程序版（基于微信 openid）。

## 目录

- `index.html` — 主页面
- `css/style.css` — 红色主题样式
- `js/app.js` — 随机配色 / 敏感词审查 / 删除权限 / 云端同步逻辑
- `config.js` — LeanCloud 云端配置（需填密钥）
- `miniprogram/` — 微信小程序版（云开发，openid 权限校验）
