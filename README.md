# 青春诗会 · 诗歌接龙

团日活动用的诗歌接龙网页样本。每次进入自动随机分配一种专属颜色（高饱和，不含白/灰），红色主题、手机端优先；支持多句按回车分行、常见敏感词自动审查、本人可删自己的诗句 + 管理员可删任意诗句。

## 文件结构

- `index.html` — 页面结构（含注意事项、创作区、接龙列表）
- `css/style.css` — 红色主题样式（手机端优先）
- `js/app.js` — 逻辑：随机取色、分行、敏感词审查、删除权限、数据层（云端/本地双实现）
- `config.js` — 腾讯云开发 CloudBase 云端配置（需填环境 ID）
- `miniprogram/` — 微信小程序版（基于云开发，权限更严格）

直接用浏览器打开 `index.html` 即可（无需本地服务器）。

## 开启云端同步（可选，推荐）

默认数据存浏览器本地（仅本机可见）。要让**浏览器和微信打开后数据互通**，需配一个免费云数据库（本项目用腾讯云开发 CloudBase）：

1. 开通云开发：打开 https://cloud.tencent.com/product/tcb（有免费额度）。如果你已在微信开发者工具里开通了云开发，同一环境在腾讯云控制台也能看到。
2. 进入你的**云开发环境** → 复制**环境 ID**（形如 `your-env-id-xxxxx`）。
3. 在该环境的「安全配置 / Web 端」开启 **Web 端访问**，并把你的页面域名加进**安全域名**（本地测试可加 `localhost`；GitHub Pages 页面加 `https://il-cyber.github.io`）。
4. 打开 `config.js`，填入 `envId`（`region` 按控制台区域填，通常 `ap-shanghai`）。
5. 在云开发「数据库」里新建集合 `poems`，权限设为「所有用户可读，仅创建者可读写」。
6. 刷新页面，底部提示变为「云端已同步 · 所有设备实时共享」即生效。

> 说明：网页版为**客户端直连**云数据库，删除权限是"客户端校验本人/管理员"；如需服务端强制校验的更安全版本，请使用 `miniprogram/` 目录下的微信小程序版（基于微信 openid）。

## 管理员口令

- 网页版：`js/app.js` 顶部 `ADMIN_CODE = '2026'`，可按需修改。
- 小程序版：`miniprogram/cloudfunctions/becomeAdmin/index.js`。

## 常用修改

- 换活动主题文案：改 `index.html` 顶部与注意事项区。
- 增删敏感词：改 `js/app.js` 里的 `SENSITIVE_WORDS` 数组。
- 换配色：改 `js/app.js` 里的 `PALETTE`（注意别用白/灰色）。
