# 青春诗会 · 诗歌接龙

团日活动主题的诗歌接龙网页样本（移动端优先），红色主题。

## 功能

- 每次进入自动随机分配一种接龙颜色（高饱和、不含白灰）
- 多行输入按回车分行显示
- 常见敏感词自动审查，命中即拦截
- 本人可删除自己发表的诗句，管理员可删除任意诗句（页脚「管理员入口」，口令见 `js/app.js` 的 `ADMIN_CODE`）
- 数据暂存于浏览器 `localStorage`（网页样本用，后续可迁移微信小程序 + 云开发）

## 使用

直接用浏览器打开 `index.html` 即可预览（建议手机视口或真机打开）。

## 说明

本版本为网页样本，数据为本地模拟；真正上线微信小程序时需将数据与权限校验迁移到云开发（云数据库 + 云函数 + openid）。
